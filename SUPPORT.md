# Support

Codex Watch is the public name for the `codex-watch` repository.

Use GitHub issues for reproducible, non-sensitive questions and defects.
Include the version or commit, platform (watchOS/macOS), expected behavior,
observed behavior, and a minimal reproduction that does not include audio,
transcripts, pairing codes, certificate phrases, or Codex thread identifiers.

Use [SECURITY.md](SECURITY.md) for vulnerabilities and private data. RSI Tech
does not guarantee support for unreleased branches, modified builds, unsigned
sideloads, or undocumented environments.

Physical Apple Watch install, CoreDevice tunnels, Speech authorization, and
Codex App Server versions are operator/runtime gates. A green simulator or CI
run is not physical-Watch proof.

Public and confidential contact: [info@rsitech.ai](mailto:info@rsitech.ai).
